# Van Halı Yıkama

**Halı yıkama hizmetleri için modern, yönetilebilir ve SEO odaklı web sitesi**

🌐 **Canlı proje:** https://vanhaliyikama.tr/

Proje; hizmetlerin güçlü görsel içerikle sunulması, mobil kullanıcı deneyimi ve yerel arama görünürlüğü hedeflenerek geliştirildi.

## Projede geliştirilenler

- Responsive kurumsal tasarım
- Yönetilebilir içerik altyapısı
- Video tabanlı hero alanı
- Mobil video optimizasyonları
- Hizmet ve iletişim bölümleri
- Sık Sorulan Sorular içerik yapısı
- Yerel SEO çalışmaları
- Teknik SEO optimizasyonları
- Sitemap ve robots.txt
- Schema.org yapılandırılmış verileri
- AI/LLM keşfedilebilirlik altyapısı
- Performans ve cache iyileştirmeleri

## Teknolojiler

PHP · HTML5 · CSS3 · JavaScript · Responsive Design · Video Web · Technical SEO · Schema.org
